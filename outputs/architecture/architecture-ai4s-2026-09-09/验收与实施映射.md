# AI4S技术验收与实施映射

创建：2026-09-09｜更新：2026-09-23｜产品V0.13／技术T1.3｜当前均为测试规格，尚未执行软件或真实试点验收

每个测试包记录需求、对象与版本、API、状态、角色、输入文件指纹、事件顺序、期望输出、实际输出、时间及执行人。设计完成、代码实现、自动测试、真实试点四种状态分别记录；下表不预填后三类结果。

## 2. 技术边界和故障场景

| 场景 | 注入条件 | 断言与证据 |
|---|---|---|
| T01 权限全入口 | 用户甲引用用户乙项目ID；检查列表、搜索、下载、Admin、模型与缓存 | 无受限正文或条数泄漏；创建及详情权限一致；拒绝日志可定位 |
| T02 并发提交／租约 | 相同幂等键并发、同键异内容、旧Worker租约过期后返回 | 同输入仅一业务结果，异内容409，过期fencing_token不能写当前状态 |
| T03 事件故障 | DB提交后投递器崩溃；发布确认丢失；消费者在提交后断开 | Outbox可补投、Inbox防重，stream_seq缺口从EventStore补拉，业务revision不用于消费游标，业务无多发 |
| T04 未知付费与预算 | 两任务接近预算，供应商已收请求但本地超时；断电后恢复 | 预留不超已知上限，未知不释放；队列／恢复不自动再付费，完成对账才继续 |
| T05 导入与证据 | 同材料重复版本、跨组同族、乱码RIS、扫描PDF、多栏与公式缺失 | 保留来源和错误；不污染holdout、不自动判无证据；补录有原页与核查 |
| T06 Gold精确边界 | 有效总量49/50、Gold正例零分母、未知命中、查全或实际结果查准84.96%、调优／独立分区正负例缺项 | 只真正合格的≥50及两个阶段两项指标均≥85%通过；Gold负例不进入查准分母，显示舍入不改变决定 |
| T07 审批并发 | Admin直接改通过、两个审核者同时修改、审核后许可变更 | 直接编辑无入口，revision冲突可恢复，发布按当前许可拒绝 |
| T08 删除与恢复 | 删除请求、30天到期、许可更短、缓存和向量残留；旧备份恢复 | 立即禁用，定时滞后不允许读；内容按期清；日记重放后不复活撤权 |
| T09 关键日记中断 | 意图已写DB未提交、DB提交完成标记未写、远端日记不可用 | 明确待对账；撤权保守拒绝，付费未知不重发，奖励不重复；不能虚报原子提交 |
| T10 主机丢失 | 切断主机，在新环境恢复DB/WAL与文件，并重放关键日记 | 共同恢复点损失≤1h，服务恢复≤4h；文件校验、许可及副作用检查均通过才开服务 |
| T11 容量与交互 | 10账号、3并发，10项目各2000题录/200全文，同时执行受控后台任务 | 固定API清单p95≤2s，任务受理≤2s；记录CPU/内存、样本大小、错误率、队列时间；图截取不影响总统计 |
| T12 模型质量与输入指令 | 固定输入对比基线／优化；材料包含要求改规则、外发秘密的文本 | 无工具／权限越界；冻结各项质量指标不低于基线、人工工作量不增加且无新增严重科学错误，随机比较方法预先固定；费用完整可对账 |
| T13 过滤流与多事件 | 同一事务先普通发布再资格事件；无关类型、逆序、重复、快照后新订阅 | 独立stream_seq连续，完整信封推进水位；一次发奖，无永久等不存在前驱；跨流按已提交依赖核验 |
| T14 跨模块发布回滚 | prepare_eligibility成功后外层发布事务异常；再重试成功并重复通知 | 失败时Publication、资格和两个Outbox均不提交，成功时同提交；仅权益模块写资格，唯一奖励 |
| T15 迟到可用性 | 第31天暂停、第51天恢复通知到第60天才达；第50天激活B，夹杂重复事件 | 激活先补权威水位；迟到校正追加记录，最终与按时通知一致，A至110／B从111，无旧余额新授权 |
| T16 旧DB重建副作用 | 只留操作前DB；日记含灾前新资格、激活、跨资产转用、一次付费请求 | 资格唯一、目标与余额确定、request_id／预算可对账；缺收据或字段保持受限，不猜成功；恢复正文权限仍独立 |
| T17 部分接纳确认 | 用户确认100条，管理员改80条；用户再次确认后又改79条 | 80条未确认时不发布；再次变79条后旧确认不适用，均不授奖 |
| T18 完整时段许可 | 许可仅余30天申请90天；FIFO延期跨到期日；转用剩70天但新目标许可60天 | 不激活或保持待选择，额度不消耗；重排重新核验，不能先承诺后用停表补救 |
| T19 独立切面 | 个人模板应用到项目后双方分别修改；其他成员查看；显式升级 | 双方不自动覆盖，不外泄私人模板；升级建项目新版，历史报告仍绑定旧版 |
| T20 会话与CSRF | 匿名API、过期会话、已登录无权、缺CSRF写入、匿名登录缺CSRF | 分别返回403与明确业务码，登录自身受CSRF保护；前端不将全部403当未登录 |
| T21 备份链过期 | 30天边界位于两次周全备之间，旧基础备份及依赖链过期 | 不保留超上限正文以扩大窗口、不保留断链恢复点；实际可恢复范围准确，最近共同点仍满足RPO，删除最迟消除日可核验 |
| T22 原子建项与隔离 | 同用户同幂等键并发、异内容重用、事务每个写点故障、跨用户相同键 | 同输入返回同一项目，异内容409；任一点失败全部回滚；键仅在用户域唯一且项目列表不越权 |
| T23 范围任务恢复 | 规则树分支、模型任务超时／失败／迟到、用户在任务期间修改答案 | 规则结果同步确定；202任务绑定输入版，失败保留答案并给恢复动作，迟到结果不覆盖新版，只归历史建议 |
| T24 候选来源与接受 | 私有图谱、相邻授权图谱和模型各给候选；权限到期；模型尝试直接写正式概念 | 只返回当前可读候选及来源；到期候选不可取用；只有用户接受命令创建ConceptVersion，模型无正式写入口 |
| T25 工作流投影 | Outbox延迟、重复／乱序事件、命令后立即读取、删除投影再重建 | 立即重算提供当前可恢复步骤；重复乱序不倒退；从业务事实重建一致，投影差异不改变批准事实 |
| T26 执行总体与多批次 | 同一SearchRun分批导入、重复上传、缺页声明、去重规则升级 | ImportBatch不可变且保留来源；总体版本可追溯，缺失时不完整；新去重规则建新版，旧抽样仍绑定旧总体 |
| T27 查准策略与样本 | 全量／分层抽样、固定种子、极小层、未判定标签、看结果后尝试换策略 | 仅启用策略可选；样本成员、权重和95%区间可复算；不足时不可判定；同总体不得通过事后换版抬高指标 |
| T28 评估包隔离 | 独立Gold和独立查准样本封包，暴露其中任一标签／误差后再验收 | 整包转调优且不可恢复，原验收历史保留；系统要求新的无暴露Gold与查准样本组成新包 |
| T29 停止、语料、准入与许可 | 四类停止、停止后未冻结／已冻结语料、各分析字段缺失、许可在上传后撤回 | 仅validated显示双85%；语料独立冻结；逐能力三态正确；撤权立即阻断外发和交付，历史任务不绕过当前许可 |

## 3. 真实选题试点

使用“铁死亡介导癌症放疗抵抗”作为真实输入方向，保留其假说性质，不预设它已经成为证实因果。研究者按实际可访问平台建立任务，提供来源许可、执行条件和材料，平台记录必要主检索依赖。

执行链为登录→新建项目→范围访谈与关键词确认→拆块／方案追问→方案与当前批次确认→多平台配置→粗检索与种子→词表／知识→正式检索→Gold查全与结果查准迭代（至少两轮）→独立评估包→停止决定→固定语料及逐模块准入→导航→候选证据补查→三关与受邀专家核查→选定课题决策包。受保护材料转研究分析需先封存退役。实际合格候选不足3个按实报告，不补造候选数量。

试点证据包包含登录与建项记录、范围版及建议来源、工作流投影重建、执行式／入口条件、多批实际回传、Gold来源分组与命中核验、ResultPopulationVersion、查准策略／样本／区间、独立评估包、停止决定、固定分析语料、逐模块准入、可定位原文、方法配置、候选依赖与意见、模型输入清单／质量对照／费用账本、用户完成与等待步骤。没有真实资料或审核者时只可记讨论稿和待核查，不能预先写结论通过。
