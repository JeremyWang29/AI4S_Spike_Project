# AI4S Research Decision Platform

This directory is the new controlled platform. The legacy `ai4s-research-decision-platform/` remains a read-only migration source and is not imported as an authority for permissions, evaluation, or approval state.

## Run locally

Use Python 3.12 and Node 24.12 or later. The Django development database defaults to SQLite only for local checks; deployment explicitly selects PostgreSQL 17. The production path is the Compose manifest in `deploy/`.

The current implementation establishes the contracts and executable domain behavior for M0–M4. Real platform rules and licenses, scientific methods, model quality baselines, capacity, image digests, remote journal transport, and RPO/RTO remain blocked until evidence is recorded.
